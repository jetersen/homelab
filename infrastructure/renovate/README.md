# Renovate

Configure repository policy through the [shared Forgejo preset](../../.renovate/forgejo.json)
and each repository's `.forgejo/renovate.json`. Set Forgejo's default merge method
to `fast-forward-only` and disable other merge methods. Required checks must test
the PR head; stale branches are regenerated by Renovate with the bot identity.

The operator's [schedule](../../kubernetes/apps/renovate/jobs/renovatejob.yaml)
discovers repositories and queues dependency scans. Native Forgejo webhooks handle
merges and Renovate checkboxes. Add the [refresh Action](../../.ci/actions/renovate-refresh/action.yaml)
on main pushes and manual dispatch for changes that native webhooks do not handle.
Configure its `RENOVATE_WEBHOOK_TOKEN` secret from the operator's webhook credential.
Webhook delivery failures and exhausted worker retries can be retried with manual
dispatch; the next discovery also reconciles missed events.

Use separate Forgejo tokens for bot repository writes, package reads, and webhook
administration. Store them, the metadata-read GitHub App credentials, and registry
credentials in the SOPS manifests. Actions OIDC tokens cannot be reused by pods.
The worker exchanges the GitHub App key for a short-lived metadata token at startup.
Rotate credentials by updating the encrypted manifests and matching Action secret;
webhook authentication changes also require updating existing hook headers.

The [worker image](worker/Dockerfile) runs the live compatibility gate on every
configuration load, including retries. A missing credential or rejected gate aborts
the run. It includes Nix; Renovate's Containerbase installs other required tools in
the repository checkout used by post-upgrade commands. Keep the explicit command
allowlist narrow.

The [operator patch](operator/pending-events.patch) uses priority to retain one
follow-up request received during a running job. Without it, 6.5.1 acknowledges
those events without queuing a run. The image build tests coalescing, successful
completion, and failure. Remove the patch only after verifying equivalent upstream
behavior. Image releases use the shared publication helpers through `publish-renovate.yaml`.

Before switching worker ownership, suspend the RenovateJob and wait for running
jobs to finish. For rollback, leave it suspended and restore the previous Actions
worker from Git history. Never enable both worker paths simultaneously. Cache
contents are disposable and are not a recovery prerequisite.
