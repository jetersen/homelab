# Renovate

Configure repository policy through the [shared Forgejo preset](../../.renovate/forgejo.json)
and each repository's `.forgejo/renovate.json`. Set Forgejo's default merge method
to `fast-forward-only`, disable other merge methods, and block outdated PRs in
branch protection. Required checks must test
the PR head; stale branches are regenerated by Renovate with the bot identity.

The operator's [schedule](../../kubernetes/apps/renovate/jobs/renovatejob.yaml)
discovers repositories and queues dependency scans. Native Forgejo webhooks handle
merges, default-branch pushes, and Renovate checkboxes. Retry failed webhook
deliveries in Forgejo or request another run through the Dependency Dashboard;
the next discovery also reconciles missed events and exhausted worker retries.

Use separate Forgejo tokens for bot repository writes, package reads, and webhook
administration. Store them, the metadata-read GitHub App credentials, and registry
credentials in the SOPS manifests. Actions OIDC tokens cannot be reused by pods.
The worker exchanges the GitHub App key for a short-lived metadata token at startup.
Rotate credentials by updating the encrypted manifests;
webhook authentication changes also require updating existing hook headers.

The [worker image](worker/Dockerfile) runs the live compatibility gate on every
configuration load, including retries. A missing credential or rejected gate aborts
the run. The source adapter implements Renovate's automerge retry hook, which the
released Forgejo adapter lacks, so eligible PRs are re-armed for native CI-gated
merging on each run, including unchanged branches. New PRs use the same path, with
bounded retries while Forgejo calculates mergeability. Its tests reject rebase
fallback and review-only updates.
Upgrade the base image and pinned source together; the build rejects a version
mismatch. Rebuild generated imports through the upstream generator.
It includes Nix; Renovate's Containerbase installs other required tools in
the repository checkout used by post-upgrade commands. Keep the explicit command
allowlist narrow.

The [operator patch](operator/pending-events.patch) adds default-branch push
subscriptions and filtering, and uses priority to retain one follow-up request
received during a running job. Release 6.5.1 otherwise ignores pushes and drops
notifications received while running. The image build tests push filtering, hook
synchronization, and follow-up requests after success or failure. Remove the patch
only after verifying equivalent upstream behavior. Image releases use the shared publication helpers through `publish-images.yaml`.

Before switching worker ownership, suspend the RenovateJob and wait for running
jobs to finish. For rollback, leave it suspended and restore the previous Actions
worker from Git history. Never enable both worker paths simultaneously. Cache
contents are disposable and are not a recovery prerequisite.
